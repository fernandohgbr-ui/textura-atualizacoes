# Textura — atualizações

Este repositório guarda só as versões publicadas da Textura (assistente com IA no topo da tela, por Textura Labs).

- Cada versão é uma **Release** com `Textura-Setup.exe`, `Textura-Portatil.exe` e `latest.json`.
- O app confere `releases/latest/download/latest.json`. Esse arquivo é **assinado**: a Textura só instala se a assinatura conferir com a chave pública que vem dentro do app **e** se o SHA-256 do instalador baixado bater com o do `latest.json`.
- O código-fonte não fica aqui.

Para instalar manualmente, baixe o `Textura-Setup.exe` da versão mais nova em **Releases**.
